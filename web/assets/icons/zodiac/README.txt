십이지 아이콘 (온명 원본)

캔바 "딸깍" 문서 2~13페이지에 한 장씩 올려 두신 아이콘을 받아 넣은 것입니다.
지지 순서 그대로: 자 축 인 묘 진 사 오 미 신 유 술 해

배경은 투명이고 선만 남아 있어서, 화면에서 색을 입혀 씁니다.
그래서 천간 색 동그라미 안에서는 흰색으로 나옵니다.

── 더 선명한 파일로 바꾸고 싶다면 ──
지금 파일은 캔바가 만들어 주는 미리보기 이미지에서 뽑아낸 것이라
원본보다 선이 조금 부드럽습니다.
캔바에서 직접 내려받은 PNG(투명 배경)가 있다면 같은 이름으로 덮어쓰기만 하면 됩니다.
크기는 512×512 정도면 충분합니다.

── 다시 기본 아이콘으로 돌리려면 ──
web/assets/js/config.js 에서
  zodiacIcons: { custom: true, ... }  →  custom: false
로 바꾸면 코드에 그려 둔 기본 아이콘이 나옵니다. (파일은 그대로 둬도 됩니다)
