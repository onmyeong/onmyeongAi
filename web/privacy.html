개인정보처리방침

온명 반지공방(이하 '온명')은 회원이 맡긴 개인정보를 꼭 필요한 만큼만 받고, 안전하게 보관합니다.

1. 받는 정보

  • 카카오 로그인 — 닉네임, 이메일(동의한 경우)
  • 직접 입력하는 정보 — 생년월일, 태어난 시각, 성별(선택), 이름(선택)
  • 리뷰와 이벤트 — 리뷰 내용과 사진, 인스타그램 게시물 주소 또는 인증 캡처
  • 주문과 A/S — 주문자 이름, 연락처, 반지 정보(호수 · 각인 문구 등)

2. 쓰는 곳

  • 회원 확인과 로그인 유지
  • 내 사주 · 신년운세 저장, 커플 연결
  • 리뷰 게시, 이벤트 참여 확인과 당첨 안내
  • 반지 제작 진행 상태 안내, A/S 처리

3. 보관 기간

  • 회원 정보는 탈퇴하면 바로 삭제합니다.
  • 이벤트 인증 자료는 이벤트가 끝나고 30일 뒤 삭제합니다.
  • 주문 · 결제 기록은 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 5년, 소비자 불만 · 분쟁 처리 기록은 3년 보관합니다.

4. 다른 곳에 주는 경우

회원 정보를 다른 회사에 팔거나 넘기지 않습니다. 다만 사이트 운영을 위해 아래 서비스를 이용합니다.

  • Supabase Inc. — 회원 정보 · 리뷰 · 사진 보관 (데이터는 서울 리전 서버에 저장)
  • 카카오 — 로그인 처리
  • GitHub — 웹사이트 화면 제공 (회원 정보는 보관하지 않음)
